# ExecPlan / PLANS.md

Use this skill when a task:
- touches schema + API + retrieval/policy, OR
- is likely >30 minutes, OR
- has multiple interdependent steps.

## Procedure
1) Create or update `PLANS.md` with:
   - objective
   - scope (in/out)
   - step-by-step checklist
   - rollback plan
   - test plan
2) Execute steps one at a time, checking off progress.
3) Update docs and tests as you go.
